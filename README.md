# 🐷 Pigreen

> Um aplicativo interativo e lúdico focado no cuidado e desenvolvimento, com mecânicas inspiradas no estilo Tamagotchi.

O **Pigreen** é um projeto mobile construído com foco em fluidez, validação de dados em tempo real e uma experiência de usuário (UX) acolhedora e minimalista. 

---

## ✨ Funcionalidades (Features)

- **Animações Nativas:** Tela de splash interativa e transições suaves (Bottom Sheet) utilizando a API `Animated` do React Native.
- **Fluxo de Autenticação Seguro:** Telas de Login e Cadastro com validação dinâmica de campos (força de senha, confirmação de dados e campos obrigatórios).
- **Componentização:** Arquitetura de UI modular, separando a lógica de negócio dos componentes visuais (`AuthInput`, `CustomInput`, `DatePickerField`).
- **Armazenamento Local:** Utilização do `AsyncStorage` para simulação de um banco de dados local na etapa de prototipagem.
- **Preparado para API:** Integração planejada com um Back-End construído do zero em **Python (FastAPI)**.
